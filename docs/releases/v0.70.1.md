# Win-CodexBar + Mobile Connect v0.70.1

The first stable Mobile Connect release offers a directly downloadable **Win-CodexBar-Mobile-Connect.exe**. Save and run it on Windows 10/11 x64 with Microsoft WebView2 Runtime; ZIP extraction and Node.js are unnecessary.

- Renamed the app/repository to explain the Android connection feature. README translations, update/support/website links and owned CI now point to this fork.
- Added detected LAN/Tailscale endpoint selection under **Advanced → Android sharing**. Same-tailnet mobile access needs no exit node; the app does not alter VPN/firewall settings.
- Shares cached PC local-log token counts and estimated USD costs for today, 30 days and the selected period where known, with independent aggregation time/date and sanitized model metadata.
- [Android v0.9.7](https://github.com/lingmulongtai/CodexBar-android/releases/tag/v0.9.7) adds phone/Windows acquisition modes, automatic known-provider discovery, optional phone exceptions, retained source/account histories and PC local-usage detail cards.
- Preserves Mobile Preview settings, product identifier, startup/toast identities, protocol version and pairing keys. Provider collectors remain the upstream implementation.

Windows must stay running. Android polls at normal refresh times; offline Windows does not silently switch to a phone account. Local PC totals may include multiple accounts; USD costs are estimates, not bills. Unknown numbers remain unknown. Gemini means Gemini CLI, not Google Gemini Apps.

The Windows EXE is **unsigned** and uses no upstream certificate or installer. Verify `SHA256SUMS` and `build-provenance.json`. Updates are manual: exit and replace the EXE. The Android APK retains its production signature.

Native Windows/Kotlin interoperability, Tailscale-address listener/receiver tests, Android API 36.1 screenshots/mode switching, source/migration/privacy/concurrency tests and locked builds were exercised with synthetic data. CUA Driver is unavailable; Windows.Graphics.Capture records real native pixels. Physical-phone, off-LAN Tailscale phone, live-account, launcher, tray-menu and Samsung Now Bar acceptance remain separate and unverified.
